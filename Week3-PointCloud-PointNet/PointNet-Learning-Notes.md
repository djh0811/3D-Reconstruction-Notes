## 一、什么是点云？

**点云（Point Cloud）** 是三维空间中一组离散点的集合，每个点至少包含 **(x, y, z)** 坐标，有时附带颜色、强度（LiDAR 反射率）等属性。它可以由 LiDAR 扫描仪、深度相机、或 SfM（Structure from Motion）算法生成。

和我们熟悉的 2D 图像对比：

| | 图像 (Image) | 点云 (Point Cloud) |
|------|------------|-----------------|
| **数据结构** | 规则网格（H×W 像素矩阵） | 无序点集——点的排列顺序不携带任何信息 |
| **维度** | 2D | 3D |
| **邻域** | 上下左右固定 8 邻域，索引即坐标 | K 近邻或半径邻域，无固定拓扑结构 |
| **稀疏性** | 每个像素都有值（稠密） | 只在物体表面有点，空间中大部分为空（稀疏） |
| **不变性要求** | 平移不变性（CNN 天然满足） | 置换不变性 + 刚体变换不变性 |

> 💡 **点云处理的核心难题：** 一个包含 N 个点的点云有 **N!** 种排列方式——但都表示同一个物体。一个能处理点云的神经网络必须对输入的**排列顺序完全不敏感**。这就是"置换不变性（Permutation Invariance）"。

举个例子：你用 LiDAR 从左到右扫一遍房间，和从右到左扫一遍，点存储的顺序完全不同——但房间还是那个房间。网络不能因为顺序变了就输出不同的结果。

## 二、PointNet（CVPR 2017）

在 PointNet 之前，要把深度学习用到点云上，必须先做**预处理**：要么把点云转成 3D 体素网格（计算量巨大），要么投影成多张 2D 深度图（丢失 3D 信息）。PointNet 是第一个**端到端直接吃原始点云**的深度网络。

### 2.1 三个不变性要求

PointNet 的设计围绕点云必须满足的**两个不变性**展开：

#### ① 置换不变性（Permutation Invariance）

打乱 N 个点的输入顺序，输出不变。

```
f(x₁, x₂, x₃, x₄) = f(x₃, x₁, x₄, x₂) = f(x₄, x₂, x₁, x₃)
```

这是**点云最根本的性质**——点的排列顺序不携带任何几何信息。CNN 做不到这一点（图像像素顺序一改，卷积结果就变了）。

#### ② 刚体变换不变性（Rigid Transformation Invariance）

点云整体旋转或平移后，语义标签不变。

```
f(R·P + t) = f(P)
```

一把椅子旋转 90° 仍然是椅子。但网络看到的 (x,y,z) 坐标全变了——需要一种机制让网络**对旋转不敏感**。

### 2.2 解决置换不变性：对称函数

什么样的函数能让输入顺序不影响输出？答案：**对称函数（Symmetric Function）**。

> 📐 **对称函数的定义：** 交换任意两个输入，输出值不变。
>
> **常见的对称函数：** Sum（1+5+3=9）、Max（max(1,5,3)=5）、Average——交换输入顺序，结果不变。
>
> **不是对称函数的例子：** 取第一个元素——first(1,5,3)=1，first(3,1,5)=3，顺序变了结果就变了。

PointNet 的精妙之处：用一个 **Shared MLP** 把每个点独立映射到高维特征空间，然后在特征维度上做 **Max Pooling**——max 就是一个天然的对称函数。

```
PointNet 的对称函数 = Max( h(x₁), h(x₂), ..., h(xₙ) )

其中 h 是共享 MLP（所有点用同一个网络），Max 在 N 个点的每个特征维度上取最大值
```

### 2.3 解决刚体变换不变性：T-Net

点云旋转后 (x, y, z) 全变了，但语义不该变。PointNet 的做法是：在输入层和特征层之前各加一个微型网络 **T-Net**，**自动学习一个最优的变换矩阵**，把点云"摆正"。

```
输入点云 (N,3) → T-Net(预测3×3矩阵) → 矩阵乘法对齐点云
    → Shared MLP (3→64→64) → T-Net(预测64×64矩阵) → 矩阵乘法对齐特征
    → Shared MLP (64→128→1024) → Max Pool → (1,1024)
```

- **第一个 T-Net（输入变换）**：预测一个 3×3 旋转矩阵，作用在原始 xyz 坐标上，相当于把任意姿态的物体"转正"。
- **第二个 T-Net（特征变换）**：预测一个 64×64 矩阵，在高维特征空间中对齐特征——因为不同物体的特征分布可能也有偏差。

两个 T-Net 都通过一个**正则化项**约束，让预测的矩阵接近正交矩阵（旋转矩阵必须是正交的）。

### 2.4 完整网络结构

```
Input(N,3) → T-Net(3×3) → MLP(64,64) → T-Net(64×64) → MLP(64,128,1024) → MaxPool(1024) → FC(512,256,k)
```

- 分类任务：最后 FC 输出 k 类分数
- 分割任务：全局特征拼接到每个点的中间层特征上

### 2.5 PointNet 为什么在场景分割上表现差？

> ❌ **核心问题：只有全局特征，没有局部上下文。**

PointNet 对**每个点独立**提取特征（Shared MLP 逐点运算），然后用一次全局 Max Pooling 得到整个点云的描述。对于**分类**任务，这没问题——你只需要知道"这是一把椅子"。

但对于**场景级语义分割**（比如：这个点是屋顶还是地面？这个点是桌子腿还是椅子腿？），问题就来了：

1. **点与点之间没有交互**：每个点的特征完全独立于它的邻居。判断一个点是不是"桌子边缘"需要看它周围的点是不是在同一平面上——但 PointNet 不知道邻居的存在。
2. **局部几何结构丢失**：一个平面上的点（桌面）和一个角上的点（桌角）在 PointNet 看来只是坐标不同的一堆独立点，卷积网络里那种"边缘检测→纹理→部件→物体"的层次化理解完全不存在。
3. **对复杂场景无能为力**：室内场景有几十种物体、不同尺度。PointNet 的单一全局特征（1024 维向量）要描述整个房间——信息被过度压缩，细节全丢了。

> 打个比方：PointNet 把一张桌子的所有点混在一起做全局判断——知道是桌子，但分不清哪是桌面、哪是桌腿。我们需要的是像 CNN 那样，先看局部邻域（"这里有个平面"），再扩大感受野（"这个平面连着四条腿"），最终理解全局结构。

这个需求催生了 PointNet++。

## 三、PointNet++（NeurIPS 2017）

PointNet++ 的核心思想一句话：**仿照 CNN 的金字塔结构，在点云上做层次化的局部→全局特征提取。**

CNN 怎么做？第一层卷积看 3×3 邻域（边缘），第二层看 5×5（纹理），越深感受野越大，最终理解整张图。PointNet++ 要做的就是在**不规则、无序**的点云上复现这一机制。

### 3.1 总体架构：Encoder-Decoder

```
N个点(B,3,N) → SA1(N→1024) → SA2(1024→256) → SA3(256→64) → SA4(64→16)
    → FP4(16→64) → FP3(64→256) → FP2(256→1024) → FP1(1024→N) → 分类头(每点→8类)
```

- **SA** = Set Abstraction（编码器，逐层降采样）
- **FP** = Feature Propagation（解码器，逐层上采样回原始点数）

### 3.2 编码器核心：Set Abstraction（SA）层

每一层 SA 实际上是三个操作的组合——这是 PointNet++ 最重要的创新：

#### ① Sampling — 最远点采样 (FPS)

从 N 个点中，选 K 个**尽可能均匀分布**的代表点。

**算法：** 先随机选第 1 个点，然后每次选**距离所有已选点最远**的那个——保证选出的点不会扎堆在一起。

例：4096 → 1024 → 256 → 64 → 16

#### ② Grouping — Ball Query

以每个采样点为中心，画一个半径 R 的球，球内所有邻居点构成**局部邻域**。

半径从小到大：0.1 → 0.2 → 0.4 → 0.8（深层球更大，感受野自然扩大）

#### ③ PointNet 层 — 每个局部邻域内运行 Mini-PointNet

对每个球内的点集，独立运行一个**微型 PointNet**（Shared MLP + Max Pooling），将球内所有点的特征压缩成一个**代表该邻域的局部特征向量**。这等价于 CNN 中的一次卷积。

> 🔑 **为什么这个设计如此巧妙？**
>
> - SA1（半径 0.1）：球很小，每个球只看局部几个点，学到的是**边缘、角落**级别的细节。
> - SA2（半径 0.2）：球变大，每个球覆盖更大的区域，学到的是**平面、曲面**级别的结构。
> - SA3（半径 0.4）：球更大，学到的是**物体的部分**（如屋顶 vs 墙壁）。
> - SA4（半径 0.8）：球几乎覆盖整个点云，学到的是**全局语义**。
>
> 这和 CNN 的浅层→深层感受野扩大完全对应，区别只在于：CNN 在规则网格上用卷积核滑动，PointNet++ 在不规则点云上先采样再分组再 Mini-PointNet。

### 3.3 解码器：Feature Propagation（FP）层

SA 层把点数从 4096 压缩到 16——适合分类，但语义分割需要**每个点都有预测**。FP 层负责把压缩的特征"广播"回原始 N 个点。

FP 层做两件事：

#### 距离加权插值

对于待插值的目标点，找离它最近的 3 个源点，用**距离的倒数做加权平均**：

```
f(x) = Σ(wᵢ × fᵢ) / Σwᵢ,  其中 wᵢ = 1 / d(x, xᵢ)
```

离得越近权重越大。

#### Skip Connection（跳跃连接）

把**对称 SA 层的低层特征**拼接到插值结果上：

```
FP 输入 = 插值特征 ⊕ SA 跳跃特征
```

低层 SA 有细粒度几何信息（边缘、角落），高层有语义信息（这是什么物体）——两者结合，既有细节又有语义。

### 3.4 分类头（Prediction Head）

FP 解码器最终输出每个点 128 维特征。分类头就是两层 1×1 卷积：

```
Conv1d(128 → 128) → BN → ReLU → Dropout(0.5) → Conv1d(128 → 8)
```

输出 (B, 8, N)，每个点的 8 个分数代表属于 8 个类别的 logits，取 argmax 即得预测类别。
