# 如何从二维照片重建三维世界？

> 深圳大学 · 地理空间信息研究所 · 研一 · 学习笔记 · 第四周（理论）

---

## 问题定义

**人做的事情很简单：** 拿着相机绕着场景拍一圈，拍到 200~300 张 2D 照片。不同角度，不同位置，同一个场景。

**想要的事情很困难：** 给定任意一个新视角（训练照片里没出现过的），生成这个视角下的画面——就像你真的站在那里拍了一张。

```
📸 输入：200~300 张 2D 照片  →  ⚙️ 算法：重建 + 渲染  →  🖼️ 输出：任意新视角的照片级画面
```

这就是 **新视角合成**（Novel View Synthesis）。核心挑战：从离散的 2D 像素反推连续的 3D 世界——数学上是病态逆问题。

---

## 方法一：传统重建管线

> 3DGS 出现之前的主流思路——把 2D 照片一步步升级为可渲染的 3D 模型。

### 第一步：COLMAP / SfM — 从 2D 照片到稀疏 3D 骨架

COLMAP 做的是 **SfM（Structure from Motion，运动恢复结构）**。人不标注任何东西，只给了照片。COLMAP 全自动地：

**① 特征提取 → 匹配 → 三角测量 → 捆集调整**
> 在每张图上找 SIFT 特征点，在图片两两之间匹配对应关系。同一个 3D 点在不同照片上的 2D 像素坐标构成射线，多条射线在空间中相交，三角测量反推出 3D 坐标。最后用 Bundle Adjustment 同时优化所有相机位姿和 3D 点位置，让投影误差全局最小。

> **COLMAP 最终输出三个文件：**
> - `cameras.bin` — 相机内参（焦距、主点、畸变系数）
> - `images.bin` — 相机外参/位姿（每张照片拍摄时相机在空间的位置 + 朝向）
> - `points3D.bin` — **稀疏 3D 点云（约 5000 个点）**— 场景的骨骼

### 第二步：MVS + 网格重建 + 纹理贴图

稀疏点云只是骨架——5000 个点之间有大量空隙，传统管线继续补全：

```
稀疏点云 ~5K  →  MVS 稠密化 ~百万点  →  泊松重建 → 三角网格  →  纹理映射 → 彩色 Mesh  →  渲染出图
```

> **传统管线的问题：** 步骤多，每个步骤积累误差；网格重建对噪声敏感；纹理映射对弱纹理和高反光表面处理困难；任何一步失败，后面全白费。

## 方法二：NeRF

> Mildenhall et al., ECCV 2020。跳过点云、网格、纹理——直接用一个 MLP 神经网络把整个场景压缩进去。`隐式表示`

### 场景表示：场景 = 一个函数

NeRF 不存储任何几何体。它训练一个 MLP（多层感知机），这个网络学会回答：在 3D 空间的坐标 (x, y, z)，从方向 (θ, φ) 看过去——这个位置有东西吗（体密度 σ）？是什么颜色（RGB）？权重本身对人没有任何几何意义，但 MLP "知道"场景长什么样。

### 渲染方式：Ray Marching（射线行进）

和传统渲染完全相反——不是"把物体投到屏幕上"，而是**从屏幕像素往外射射线，沿途采样，累积颜色**：

> **发射射线 → 采样 → 查 MLP → 累积颜色**
>
> 每个像素发射一条射线，沿射线取 64~256 个采样点。每个点查 MLP 得到 (σ, RGB)，从近到远按透明度加权叠加。一张 1920×1080 的图约 4 亿次 MLP 前向传播——渲染一张图要几十秒。

### 训练：纯梯度下降

随机选一批像素射线 → Ray Marching 渲染 → 和真实照片算 L2 损失 → 反向传播更新 MLP 权重。重复几十万次，MLP 逐渐"记住"整个场景。

> **NeRF 的优势：** 不需要 SfM 的 3D 点云，不需要网格，不需要纹理。随机初始化，纯靠梯度下降学会场景。即使 COLMAP 失败了（弱纹理、重复图案），NeRF 仍然能训。

### 加速版：Instant-NGP

原始 NeRF 训一个场景要 1-2 天。Instant-NGP（Müller et al., 2022）只换了一种编码方式：

| | 原始 NeRF | Instant-NGP |
|------|----------|------------|
| **编码** | (x,y,z) → 位置编码（sin/cos 高频映射到 60 维） | (x,y,z) → 多分辨率 Hash Grid 查表（O(1)，极快） |
| **MLP** | 大 MLP（8 层 × 256） | 小 MLP（2 层 × 64） |
| **训练** | 1-2 天 | 数秒 |
| **渲染** | 几十秒/帧 | 60+ FPS |
| **代价** | — | Hash Grid 分辨率固定，无法自适应增加细节容量 → 最终质量不如 3DGS |

## 方法三：3D Gaussian Splatting

> Kerbl et al., SIGGRAPH 2023。彻底放弃隐式函数——场景不用 MLP 存，直接用几百万个 3D 高斯椭球体摆出来。`显式表示`

### 场景 = 几百万个彩色椭球

每个高斯球携带：**位置** (x, y, z)、**缩放**（沿三个轴拉多长）、**旋转**（朝哪个方向）、**不透明度 α**、**球谐系数**（从不同角度看颜色怎么变）。打开 .ply 文件就能看到场景本身——不像 NeRF 的 MLP 权重是黑盒。

### 初始化：从 COLMAP 的稀疏骨架出发

```
COLMAP points3D.bin (~5,000 个点)  →  每个点 → 1 个高斯球（默认小圆球，α=0.1）  →  初始场景 ~5,000 个高斯球
```

> **3DGS 依赖 SfM：** 如果 COLMAP 跑失败了，3DGS 就无法初始化。这是它相对 NeRF 最大的弱点——NeRF 可以随机初始化。

### 渲染：Splatting（抛雪球）

和 NeRF 完全相反——不是从像素射光线，而是**把所有高斯球一次性投影到屏幕**：3D 椭球 → 数学变换（EWA + Jacobian 近似）→ 屏幕上的 2D 椭圆 → 按深度排序 → 逐像素 Alpha Blending。没有 MLP，纯 CUDA 并行，所以比 NeRF 快 100 倍以上。

### 训练的核心创新：自适应密度控制

NeRF 训练时结构固定不变。3DGS 训练中，**高斯球的数量和分布在动态变化**：

| 操作 | 触发条件 | 效果 |
|------|---------|------|
| **Clone** 克隆 | 小高斯球梯度大 | 信息不够，复制一份增加容量 |
| **Split** 分裂 | 大高斯球梯度大 | 需要精细度，一分为二 |
| **Prune** 剪枝 | 太透明或太大 | 没用，删掉 |
| **SH** 渐进激活 | 先低阶后高阶 | 先低阶球谐（漫反射），后激活高阶（高光/反光） |

效果：**从约 5000 个高斯球增长到几百万个。** 纹理丰富区域密集，平坦白墙稀疏。训练完成的 .ply 文件就是最终产品——不需要再转点云或网格，直接用椭球从任意新视角实时渲染（100+ FPS）。

## NeRF 与 3DGS 对比分析

### 联系

> **同一个任务，同一个公式，同一条演化线。**
>
> 两者都解决新视角合成，共享 Alpha Blending 体积渲染数学公式——从近到远逐层叠加半透明颜色。区别只在于每层的颜色和透明度从哪来：NeRF 从 MLP 查询 (x,y,z,θ,φ) → (σ, RGB)，3DGS 从高斯球投影后在像素位置的值。
>
> 演化路径：原始 NeRF（大 MLP，慢）→ Instant-NGP（Hash Grid 分担记忆，MLP 变小，快了很多）→ **3DGS（MLP 全部去掉，直接存几何体，最快）**。3DGS 本质上是 NeRF 去 MLP 化的终点。

### 区别

| 维度 | NeRF | 3DGS |
|------|------|------|
| **场景表示** | MLP 权重（几 MB，隐式，黑盒） | 高斯椭球（几百 MB，显式，直接可见） |
| **渲染方式** | Ray Marching，射线采样查 MLP，秒级 | Splatting，椭球投影 + 排序 + 混合，100+ FPS |
| **训练** | 结构固定，纯梯度下降 | 结构动态变化，自适应密度控制 |
| **初始化** | 随机初始化，SfM 失败也能训 | 依赖 SfM 稀疏点云初始化 |
| **可编辑性** | 不可编辑，黑盒 | 可删/移/复制高斯球 |
| **速度与质量** | 训 1-2 天，秒级渲染（INGP 训数秒，60FPS） | 训 ~20 分，100+ FPS，质量最高 |

> NeRF 把场景"压缩"进一个函数——你问它，它算出来。
> 3DGS 把场景"展开"成几何体——椭球摆在那，直接看。
> **一个用计算换空间，一个用空间换时间。同一道题，两个解法。**

---

> 📝 **本周学习说明：** 第四周理论部分——系统梳理从 2D 照片到 3D 世界的三条技术路线：传统多视图几何管线（SfM→MVS→网格→纹理）、NeRF（隐式神经表示 + Ray Marching）、3D Gaussian Splatting（显式高斯椭球 + Splatting）。重点理解 NeRF→Instant-NGP→3DGS 的演化逻辑：逐步去 MLP 化，用显式几何替代隐式查询，用空间换时间。
